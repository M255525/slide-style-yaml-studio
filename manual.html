簡報風格工坊操作手冊

簡報風格工坊幫你產生一份 YAML 格式的「簡報設計框架」。把它跟課程講義一起放進 NotebookLM，再請 NotebookLM 產生簡報，就能讓每次生成的簡報維持同一套配色、字體、圖示與版面規則。

1. 三分鐘快速開始

  1. 在「風格圖鑑」挑一張喜歡的風格卡，按「用這個風格做簡報 →」。
  2. 在「YAML 產生器」的「從 AI 課程總覽帶入大綱」選一門課，或自己填標題與各頁內容。
  3. 按右側「複製 YAML」，再按「複製說明」。
  4. 到 NotebookLM 把 YAML 貼成文字來源，產生簡報時把「自訂說明」貼進提示欄。

2. 風格圖鑑

12 種風格取材自馬克老師做過的教學工具視覺主題，每張卡片包含：

  • 縮圖：用網頁繪製的風格示意，讓你快速感受氛圍，不是 NotebookLM 的實際輸出。
  • 適合／取材／色票：建議搭配的課程類型、靈感來源工具，以及主要配色。
  • YAML 範例（2 頁）：展開後可直接複製，包含封面與一頁內容頁，適合先試效果。
  • 用這個風格做簡報 →：切到 YAML 產生器並套用這個風格。

上方「課程類型」標籤可篩選卡片，例如只看適合「數據與表單」或「政府補助」的風格。

3. YAML 產生器

選風格與課程

換風格時，左側縮圖會用你的簡報標題即時預覽。選擇課程後會自動帶入大綱：封面 → 課程大綱 → 每個單元一頁 → 重點回顧，並依課程類型自動換成建議風格。之後若改用其他風格，下方會出現建議風格的標籤，點一下就能換回來。

帶入課程會覆蓋目前的逐頁內容。若已經改了很多，請先按「複製 YAML」留存。

簡報基本資料

  • 簡報標題、副標題、講師署名：寫進封面頁；講師署名也會出現在重點回顧頁。
  • 授課對象：選填，寫進 global_design.audience，幫 NotebookLM 調整用詞深淺。
  • 版面比例：16:9（投影）、4:3（舊式投影機）、9:16（手機直式）。
  • 文案語氣：留白則套用風格建議的語氣（灰字提示），填寫則以你的為準。

逐頁內容

每一頁可以選頁面類型、填標題，下方方框一行寫一個重點。右側按鈕可上移、下移、刪除；最下方「＋ 新增一頁」加在最後。「清空重填」會清掉標題與所有頁面，只保留風格與講師署名。

所有修改都會自動暫存在這台瀏覽器，下次打開會接續上次的草稿。

4. 九種頁面類型

同一種頁面類型套在不同風格上，會得到不同的 visual_description。例如「步驟流程」在藍圖風格是「青框方塊以直角箭頭串接」，在森林小徑風格則是「沿著虛線小徑一站一站前進」。

類型YAML type重點欄位寫成適合放什麼
封面Covertagline（只取第一行）課名、副標、講師
課程大綱Agendaitems今天的單元清單
概念說明Conceptpoints定義、原理、名詞解釋
步驟流程Stepssteps操作流程、SOP、階段
比較對照ComparisoncolumnsA vs B、優缺點、多種視角
數據重點Datapoints統計數字、指標、圖表
案例情境Casepoints實戰範例、情境題
隨堂練習Quizoptions選擇題、配對題
重點回顧Summarypoints＋signature帶走的三個重點

從課程帶入時，系統會依大綱文字自動判斷類型：含「流程、步驟、階段、→」判為步驟流程；含「比較、vs」判為比較對照；含「數據、統計、分析、指標」判為數據重點；含「案例、實戰、範例、實作」判為案例情境；其餘為概念說明。判斷不準時直接改下拉選單即可。

5. YAML 結構說明

產出的 YAML 分成兩大段：global_design 是整份簡報共用的設計規則，slides 是逐頁的版面與內容。

# 【課程錄製直播】簡報設計框架：AI 媒體與簡報設計
global_design:
  atmosphere: "線上課程錄影室、清楚易讀、講師親切陪伴"
  voice: "講師第一人稱口語……"
  aspect_ratio: "16:9"
  color_scheme:
    background: "#FFFFFF"  # 投影片白
    highlight_color: "#2563EB"  # 重點藍
  typography:
    family: "黑體"
  layout_rules:
    icon_style: "簡潔線條圖示，數量少而大"

slides:
  p1:
    type: "Cover"  # 封面
    visual_description: "白色投影片，左上大標題……"
    content:
      title: "AI 媒體與簡報設計"
      presenter: "馬克老師"
  p2:
    type: "Steps"  # 步驟流程
    visual_description: "由左到右三到五個圖示步驟……"
    content:
      title: "簡報生成五步驟"
      steps:
        - "NotebookLM 整理講義"
        - "Gem 設定視覺導演角色"
  • # 開頭是註解，給人看的，NotebookLM 也能讀懂顏色用途。
  • 所有文字都包在雙引號內，你輸入的引號或反斜線會自動跳脫，不會讓 YAML 格式壞掉。
  • 想手動微調也可以：複製後在記事本修改 visual_description 或色碼，再貼進 NotebookLM。

6. 在 NotebookLM 套用

  1. 開啟 NotebookLM，進入放有課程講義的筆記本。
  2. 按「新增來源」→「複製的文字」，貼上 YAML。建議來源名稱取「課名｜風格名稱 簡報設計框架」，方便辨認。
  3. 在「工作室」選擇產生簡報，勾選課程講義來源與這份 YAML 來源。
  4. 在自訂提示欄貼上產生器給的「自訂說明」，再按產生。
  5. 結果不滿意時，可以只換 YAML 來源（換風格），講義不用重新上傳。
YAML 只決定「長什麼樣子」，實際講解內容由講義來源提供。所以逐頁重點寫關鍵字即可，不必寫完整句子。

7. 小技巧與常見問題

生成的簡報沒有照 YAML 的配色？

確認產生簡報時有勾選 YAML 來源，並在自訂說明中寫明「依照 YAML 設計框架」。模型偶爾會偏離，可以重新產生一次，或在說明裡補一句「背景色必須是 #xxxxxx」。

頁數太多漏頁？

超過 15 頁時較容易漏頁或合併頁面，建議拆成上、下兩份 YAML 分次產生。

想用自己的課程，不在清單裡？

課程選單選「不帶入，自己填」，或按「清空重填」後逐頁輸入。也可以先帶入一門結構相近的課程，再改標題與重點。

草稿不見了？

草稿只存在目前這台電腦的這個瀏覽器。換電腦、使用無痕視窗或清除瀏覽器資料後就不會保留；重要的版本請複製 YAML 另存成文字檔。

縮圖跟 NotebookLM 產出的不一樣？

正常。縮圖是用網頁繪製的風格示意，NotebookLM 會依 YAML 描述自行繪製，細節一定有差異。

8. 使用警語

  • 本工具只產生簡報的版面與視覺設計框架（YAML），不會產生投影片本身，也不會呼叫任何 AI 服務。
  • NotebookLM 是否完全依照 YAML 呈現，取決於 Google 當下的模型版本；同一份 YAML 每次生成的結果可能不同，色碼、字體與版面僅作為設計指引。
  • 課程大綱是 AI 課程總覽的內容快照，帶入後請自行確認是否為最新版本。
  • 在本工具輸入的內容只暫存於你的瀏覽器，不會上傳到任何伺服器；貼進 NotebookLM 的內容則依 Google 的服務條款處理，請勿放入個資、客戶資料或公司機密。
  • 頂部跑馬燈的公告內容來自馬克老師的公告表單，僅為資訊通知。
  • 本工具與創作者不對使用產出內容所製作之簡報、教材或其衍生用途負責；簡報中引用的圖片、字型與商標，請自行確認授權。
